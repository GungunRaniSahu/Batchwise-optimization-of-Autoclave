# Autoclave Batch Optimizer

Internal planning tool for autoclave batch/port optimization, with login
authentication, a refreshed UI, and automatic 60-day data retention.

## What changed from the original version

1. **UI redesign** — new header/nav/card styling in `static/css/style.css`,
   templates split into `base.html`, `login.html`, `index.html`.
2. **Company logo in header** — the header and login page already look for
   `static/img/tata_logo.png`. The real logo isn't included in this codebase
   (it's your organization's trademarked asset) — copy the approved PNG file
   into `static/img/` using that exact filename. Until you do, a plain
   "TATA" text placeholder is shown so the app keeps working.
3. **Login / logout** — added with Flask-Login. Every page now requires
   sign-in (`@login_required`). Passwords are hashed (never stored in
   plaintext) in `users.json`, which is git-ignored.
4. **60-day data retention** — a background job (`scheduler.py` +
   `retention.py`) automatically deletes Excel backups and the generated
   `Optimized_Batches.xlsx` once they are older than 60 days. It runs once
   at startup and then every 24 hours. Change the window with the
   `DATA_RETENTION_DAYS` environment variable if needed.

## First-time setup

```bash
# 1. Create and activate a virtual environment
python3 -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate

# 2. Install dependencies
pip install -r requirements.txt

# 3. Set a real secret key (don't use the default in production)
export SECRET_KEY="a-long-random-string"     # Windows (PowerShell): $env:SECRET_KEY="..."

# 4. (Optional) change the retention window, default is 60 days
export DATA_RETENTION_DAYS=60

# 5. Create your first login user
python manage_users.py add admin --role admin

# 6. Add your organization's approved logo
cp /path/to/approved/tata_logo.png static/img/tata_logo.png

# 7. Run the app
python app.py
```

Then open http://127.0.0.1:5000 and sign in.

## Managing users later

```bash
python manage_users.py add operator1 --role operator   # add a user
python manage_users.py list                             # list all users
python manage_users.py remove operator1                  # remove a user
```

## Running in production

`app.run(debug=True)` is for local development only. For production, run
behind a real WSGI server, e.g.:

```bash
pip install gunicorn
gunicorn -w 2 -b 0.0.0.0:8000 app:app
```

(On Windows, use `waitress` instead of `gunicorn`.)

Suggested branch name: `feature/ui-revamp-auth-retention`
Suggested commit message: `feat: redesign UI, add login/logout auth, add 60-day data retention`


## Notes / things to double check before go-live

- Replace the default `SECRET_KEY` via the environment variable — don't
  leave the placeholder in `config.py` for a real deployment.
- `users.json` and `settings.json` are git-ignored on purpose — they hold
  credentials and site-specific settings and shouldn't be committed.
- The BIG/SMALL part classification threshold in Settings is still a
  configurable placeholder, same as in the original app — confirm it
  against your approved engineering rule.
